# did-go

A Go library for W3C Decentralized Identifiers that supports DID Core 1.0 and
DID 1.1 side by side, with separated issuer, holder and verifier roles. Standard
DID support is complete on its own; SAGE support is an opt-in advanced
extension. The design is in [`docs/`](docs/README.md); nothing is implemented
yet.
